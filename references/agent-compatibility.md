# Agent 兼容说明

本项目采用目录 + SKILL.md 元信息 + 按需参考文件的形式，不绑定单一模型。

## 兼容层级
1. **可阅读**：宿主能读 SKILL.md 和参考文件，可按工作流人工调用。
2. **可执行**：宿主还具有文件读写、命令执行、Python（脚本路径）等权限。
3. **原生发现**：宿主能在其规定的 skills 目录中自动发现并激活。
4. **实测兼容**：真实环境端到端通过；目前未对具体产品声明此状态。

## 安装示例（必须以宿主当前官方文档为准）
- Claude Code：通常可放到用户或项目的 `.claude/skills/audio-notes/`，保留整个目录。
- Codex 等支持 Agent Skills 的工具：放入该宿主当前支持的 skills 目录；目录规范随版本变化，不盲目复制其他产品路径。
- Chatbox 等支持导入 Skill 的工具：用其安装入口导入目录/包；不得因为能读取 Markdown 就声称已原生集成。
- 通用 Agent：显式读取 SKILL.md，并授予本任务所需最小权限。

无需脚本的文字总结可纯靠宿主完成。不能执行 Python 时，自动校验不可用，必须在交付中说明。不能写出文件时，不能把聊天文本伪称已生成可下载文件。

安全提示：第三方 Skill 也是代码与指令，安装前应检查；不默认自动执行来自仓库的脚本，不要求系统全盘访问权限。
